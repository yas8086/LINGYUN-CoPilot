# 灵云01号伴飞电脑 — 生产环境部署清单

> 目的：脱离开发环境、正式搭载飞艇前，逐项核对并确认系统可靠性。
> 所有命令以 `sudo` 或对应权限执行；本机为树莓派 (ARM64)。

---

## 0. 部署前必读

- 系统核心保障机制已内置：**udev 固定设备名 + systemd 开机自启/崩溃自愈 + 节点 respawn + CAN/串口自动重连 + MQTT 自动重连 + 日志上限 + NTP 同步**。
- 部署脚本统一入口：`tools/install_production.sh`（全量安装 6 项）。
- 本文档第 1~7 节为**必须完成**的配置；第 8 节为**搭载前需用户确认**的硬件/业务参数。

---

## 1. USB 设备固定命名 (udev)

**文件**：`tools/70-airship-usb.rules` → `/etc/udev/rules.d/70-airship-usb.rules`

已覆盖：
| 符号链接 | 设备 | VID:PID |
|---|---|---|
| `/dev/airship_485` | LoRa 485 集中器 (FTDI FT232R) | 0403:6001 |
| `/dev/airship_4g_at0..4` | SIM7600 4G 模块 (5 端口按接口号) | 1e0e:9001 |
| `/dev/airship_link` | **数传电台** | **待确认 (见 8.1)** |
| `/dev/airship_backup_bms` | **12S 备用电源 BMS** | **待确认 (见 8.6)** |

安装/验证：
```bash
sudo ./tools/install_production.sh --udev
ls -l /dev/airship_485 /dev/airship_4g_at0
```
> 数传电台规则当前为**注释占位**，未接入实物前无法自动识别，需按 8.1 补充。
> 12S 备用电源规则当前为**注释占位**，需按 8.6 补充。

## 2. 串口权限 (dialout 组)

- 用户 `lingyun01` **已加入** `dialout` 组（一次性，永久生效）。
- udev 规则已强制 `GROUP="dialout" MODE="0660"` 作为双保险。
- systemd 服务以 `User=lingyun01` 运行，开机全新会话天然继承组权限。

验证：`groups lingyun01` 应含 `dialout`；`ls -l /dev/ttyAMA10` 属组应为 `dialout`。

---

## 3. systemd 开机自启 + 崩溃自愈

**文件 A**：`tools/airship-device-monitor.service` → `/etc/systemd/system/`（设备监控 ROS2 系统）
**文件 B**：`tools/airship-dcdc-hold.service` → `/etc/systemd/system/`（DCDC 硬件保活，独立于 ROS2）

- 开机自启：`systemctl enable`
- 崩溃自愈：`Restart=always` + `RestartSec=3`
- 前置初始化 CAN：`ExecStartPre`
- 节点级 respawn：launch 文件中每个节点 `respawn=True`

```bash
sudo ./tools/install_production.sh --systemd --dcdc-hold
systemctl status airship-device-monitor
systemctl status airship-dcdc-hold
journalctl -u airship-device-monitor -f
```

> **DCDC 硬件保活（安全关键）**：`dcdc_hold` 是**无 ROS 依赖的独立进程**，由独立 systemd 服务管理，以 200ms 周期持续下发 DCDC 控制帧。即使 ROS2/launch/DDS 全部崩溃，DCDC 输出仍保持不断电。二进制位于 `install/airship_dcdc/lib/airship_dcdc/dcdc_hold`。

---

## 4. 日志管理 (防止撑爆 TF 卡)

**journald**：`tools/90-airship-journald.conf` → `/etc/systemd/journald.conf.d/`（SystemMaxUse=50M）
**ROS2 logrotate**：`tools/ros_logrotate` → `/etc/logrotate.d/ros`（10MB 轮转，保留 5 份）

```bash
sudo ./tools/install_production.sh --journald --logrotate
```

---

## 5. 时间同步 (NTP)

- 树莓派无 RTC，必须 NTP 同步，否则遥测时间戳/上云时间错误。

```bash
sudo ./tools/install_production.sh --ntp
timedatectl   # 应显示 "System clock synchronized: yes"
```

## 6. CAN 接口自启

```bash
sudo ./tools/install_production.sh --can 250000
```
- 主服务 `ExecStartPre` 已含 CAN 初始化兜底（若 can0 存在则 up）。

## 8. 待用户确认项 (搭载前必须落实)

### 8.1 数传电台 VID/PID (阻塞项)
`link_node` 已改用 `/dev/airship_link` 符号链接，但**当前未插数传电台**，无法自动识别（已确认：暂无法确认芯片型号）。
- 搭载前插上数传电台后：`lsusb` 查看实际 VID:PID → 填入 `70-airship-usb.rules` 的占位规则（`tools/` 下）→ 重装 udev。

### 8.2 DCDC 控制帧 fail-safe 策略 ✅ 已决策
**已确认：崩溃时保持输出。**
已实现无 ROS 依赖的 `dcdc_hold` 独立保活服务（见第 3 节），即使 ROS2 全崩仍持续发控制帧，DCDC 不断电。搭载前需部署该服务并验证。

### 8.3 MQTT broker 地址 (阻塞项)
`airship_params.yaml` 中 `cloud_node.mqtt_host` 当前为占位 `localhost`。
- 需确认 4G 云服务器 broker 公网地址/端口/账号密码后填入。

### 8.4 飞控连接 (网口 ETH/UDP)
`device_monitor.launch.py` 的 `fcu_url` 默认 `udp://:14550@10.41.10.2:14550`（网口直连飞控 ETH）。
- 树莓派 eth0 需配置静态 IP `10.41.10.100/24`（不设网关 + `never-default`），详见 [05_飞控监控与联调](./05_飞控监控与联调.md)。
- 飞控侧 SD 卡 `net.cfg` 需配置 `BOOTPROTO=static`、`IPADDR=10.41.10.2`（通过 QGC MAVLink Console 写入并重启生效）。

### 8.5 用户态 rootfs 只读/写保护 (可选加固)
如需防 SD 卡断电损坏，可评估 `overlayfs` 只读 root 方案（涉及系统改动，需单独决策）。

### 8.6 12S 备用电源 BMS 串口 VID/PID (阻塞项)
`backup_bms_node` 已改用 `/dev/airship_backup_bms` 符号链接，但**当前未插备用电源**，无法自动识别。
- 搭载前接上备用电源 USB 串口后：`lsusb` 查看实际 VID:PID → 填入 `70-airship-usb.rules` 的备用电源占位规则（`tools/` 下）→ 重装 udev。
- 若从机地址/主机信息非默认值，按实测调整 `airship_params.yaml` 中 `backup_bms_node.addr/host`。
