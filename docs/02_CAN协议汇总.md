## 一、MPPT (YQPV_SPC/SMC 系列)

**协议**: MPPT-CAN通信协议 V1.2

### 帧 ID 结构
```
只读数据: 主机发 0x14[code]xxA1 → 从机回 0x14[code]A1xx
          · 第29~25位: 0x14 (只读)
          · 第24~17位: 报文代码 (code)
          · 第16~9位:  目标地址 0xA1
          · 第8~1位:   源地址
```

### 关键只读地址段

| 地址代码 | 内容 | 关键信号 |
|---------|------|---------|
| `0x1403` | 实时电压电流 | 光伏电压(0.1V)、电池电压(0.1V)、充电电流(0.1A) |
| `0x1404` | 状态 | 充电状态、故障状态 |
| `0x1405` | 发电量 | 日/月发电量(0.1kWh) |
| `0x1406` | 总发电量 | 总发电量(0.1kWh) |
| `0x1408` | 温度 | 机内温度(0.1℃)、模块温度(0.1℃) |

### 故障状态位
| Bit | 含义 |
|-----|------|
| 0 | 电池欠压 |
| 1 | 电池过压 |
| 2 | 光伏欠压 |
| 3 | 光伏过压 |
| 4 | 充电过流 |
| 5 | 设备过温 |
| 6 | 模块损坏 |

## 二、BMS (bms_ems_v01, 三元锂 102 串)

**协议**: 完整 DBC 见 `lingyun01/BMS/102S主电源/bms_ems_v01_dbc(...).dbc`

### 关键报文 ID

> 帧 ID 为 SocketCAN 收到的 29 位扩展帧 ID(已做 `0x1FFFFFFF` 掩码, 即 DBC `0x8000xxxx` 去掉最高位)。

| 报文 | CAN ID | 关键信号 |
|------|--------|---------|
| `BattInfo02` | `0x001400` | BattVolt(0.1V)、BattCurr(0.1A,-100偏移)、SOC(0.1%)、RealSoc |
| `BattInfo01` | `0x001300` | BMS_AlarmLevel、运行状态、连接状态、绝缘电阻 |
| `CellVoltStatistic` | `0x001200` | 单体电压极值统计 |
| `CellTempStatistic` | `0x001500` | 单体温度极值统计 (1℃,-50偏移) |
| `CellVoltage_01..` | `0x003000 + 0x10*n` | 单体电压, 每帧5节, 12位信号(0.001V,+1偏移) |
| `PACKTemp` | `0x002110` | 极耳温度 8 点 (1℃,-50偏移) |
| `SOP` | `0x001100` | 充放电限值 |

### 信号分辨率速查
- BattVolt: `raw × 0.1` [V]
- BattCurr: `raw × 0.1 - 100` [A]
- SOC: `raw × 0.1` [%]
- 单体电压: `raw × 0.001 + 1` [V] (12位 Motorola 布局)
- 温度: `raw - 50` [℃]

## 三、DCDC (昊瑞昌 HRC-GFD360-48-4K)

**协议**: DCDC 通讯协议 V1.0 (总结见 `lingyun01/DCDC/母线降48V/昊瑞昌/`)

### 关键帧 ID

| 功能 | 方向 | CAN ID | 周期 |
|------|------|--------|------|
| 电源控制帧 | VMS→DCDC | `0x18EF3010` | 200ms (持续) |
| 电源状态帧 | DCDC→VMS | `0x18FF3247` | 500ms |
| 模拟量查询 | VMS→DCDC | `0x18D80047` | - |
| 模拟量回应 | DCDC→VMS | `0x18D84700` | - |

### 电源控制帧 (0x18EF3010)
| Byte | 内容 |
|------|------|
| 2 | Bit5~4: 00=关机, 01=开机 |
| 3~4 | 输出电压 (0.1V/BIT, 小端) |
| 5~6 | 输出限流 (0.1A/BIT, 小端) |

### 电源状态帧故障字节 (0x18FF3247 Byte0)
| Bit | 含义 |
|-----|------|
| 7 | 总故障 |
| 5 | 短路 |
| 4 | 过热 |
| 3 | CAN 中断 |
| 2 | 输出状态 (0停 1开) |
| 1 | 输入过压 |
| 0 | 输入欠压 |

### 模拟量回应帧 (0x18D84700)
| Byte | 内容 |
|------|------|
| 0~1 | 输入电压 (1V/BIT) |
| 2~3 | 输出电压 (0.1V/BIT) |
| 4~5 | 输出电流 (0.1A/BIT) |
| 6 | 环境温度 (1℃/BIT, -40偏移) |
| 7 | 散热器温度 (1℃/BIT, -40偏移) |
