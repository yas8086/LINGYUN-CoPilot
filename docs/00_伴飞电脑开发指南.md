# 灵云01号伴飞电脑开发指南

> 本目录包含面向伴飞电脑(Raspberry Pi 5)设备监控开发的全部技术文档。
> 当前阶段: **Phase-1 设备监控**(BMS / MPPT / DCDC) + **飞控数据监控**(PX4 二次开发)。
> 飞行控制、路径规划尚未接入; 4G 上云 MQTT 地址待定。

## 系统定位

伴飞电脑(Raspberry Pi 5)作为**机载数据中继节点**:

```
  MPPT ──┐
  BMS  ──┼── CAN总线(SocketCAN) ──► 树莓派5 解析/整理 ──► 串口数传 ──► Qt上位机(地面)
  DCDC ──┘       (250kbps, 扩展帧)   (airship_* 节点)      (JSON帧)
  飞控  ── telem2(UART) ──► MAVROS(PX4) ──► fc_monitor ──► /fc/status
  4G   ── cloud_node(MQTT) ──► 公有云(地址待定)
```

- 接收各电源设备(MPPT/BMS/DCDC)的 CAN 帧
- 解析厂家协议为结构化数据
- 通过 MAVROS 采集飞控(PX4 二次开发, 雷迅 X25 EVO, telem2 串口)状态
- 经串口数传统一下传给地面 Qt 上位机
- 经 4G + MQTT 上云(公网服务器/MQTT 地址待定)

## 快速上手

### 环境

- 树莓派5 + Ubuntu 24.04 + ROS2 Jazzy
- CAN 接入: USB-CAN 适配器, SocketCAN 接口 `can0`(250kbps)
- 飞控接入: MAVROS + USB/UART(雷迅 X25 EVO, telem2, 921600)
- 4G 上云: `airship_cloud`(libmosquitto, MQTT), 需先装 `libmosquitto-dev`

### CAN 接口初始化

```bash
sudo ip link set can0 type can bitrate 250000
sudo ip link set can0 up
# 验证
ip -details link show can0
candump can0
```

### 构建与启动

```bash
source /opt/ros/jazzy/setup.bash
colcon build
source install/setup.bash

# 启动全部设备监控节点(含飞控监控与 4G 上云)
ros2 launch airship_bringup device_monitor.launch.py

# 查看设备状态
ros2 topic echo /bms/status
ros2 topic echo /mppt/status
ros2 topic echo /dcdc/status
ros2 topic echo /fc/status
ros2 topic echo /monitor/device_alert
```

### 飞控与 4G 上云配置

| 项 | 配置 | 说明 |
|----|------|------|
| 飞控固件 | 二次开发的 PX4 | launch 使用 `px4.launch.py` |
| 飞控串口 | telem2(雷迅 X25 EVO) | 默认 `serial:///dev/ttyAMA1:921600`, 按接线调整 |
| 飞控话题 | `/fc/status` | fc_monitor 聚合姿态/位置/速度/电池 |
| MQTT 地址 | **待定** | 当前 `mqtt_host=localhost` 占位, 待公有云服务器落实后修改 |

> 修改 `src/airship_bringup/config/airship_params.yaml` 中的 `cloud_node.mqtt_host/port` 即可接入已确定的 MQTT Broker。
