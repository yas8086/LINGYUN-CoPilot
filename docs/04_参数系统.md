# 灵云01号 参数系统

> 本文档面向伴飞电脑开发者，列出飞控所有自定义参数。伴飞电脑可通过MAVLink读写参数。

## 1. 参数命名规则

| 前缀 | 模块 | 示例 |
|------|------|------|
| AS_ | 飞艇姿态控制器 (airship_att_control) | AS_ALT_P, AS_PIT_P |
| BALLOON_* | 浮力调节PID (ballast_control) | BALLOON_P_GAIN |
| BLOWER_* | 鼓风机控制 (ballast_control) | BLOWER_TAU |
| VALVE_* | 阀门控制 (ballast_control) | VALVE_OPEN_DELAY |
| TRIM_BALLOON_* | 配平控制 (ballast_control) | TRIM_BALLOON_P |
| CA_AS_* | 控制分配器物理常数 | CA_AS_K_LUP |
| LNDAS_* | 着陆检测阈值 | LNDAS_XY_VEL_MAX |

### 2.4 操纵映射

| 参数 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|------|------|--------|------|------|------|
| AS_PIT_RMAX | float | 0.349 | 0.05-1.0 | rad/s | 最大俯仰角速度(约20deg/s) |
| AS_YAW_RMAX | float | 0.524 | 0.05-2.0 | rad/s | 最大偏航角速度(约30deg/s) |
| AS_ALT_SRATE | float | 2.0 | 0.5-5.0 | m/s | 高度摇杆调整速率 |

**操纵映射**: Throttle->前进, Pitch杆->高度, Roll杆->偏航, Yaw杆->俯仰

### 2.5 力矩限制与前馈

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| AS_YAW_TMAX | float | 0.5 | 0.01-1.0 | 最大偏航力矩(推进电机差动上限) |
| AS_PIT_FF | float | 1.0 | 0-2.0 | 推进俯仰耦合前馈增益 |

**AS_PIT_FF说明**: 推进电机在重心下方1.5m, 前进推力产生抬头力矩。增益调度公式:
```
pitch_p_effective = AS_PIT_P + AS_PIT_FF * thrust_x_filtered
```
高速时增加俯仰刚度, 补偿Munk力矩失稳效应。

## 7. 伴飞电脑参数读写示例

```python
import asyncio
from mavsdk import System

async def read_airship_params():
    drone = System()
    await drone.connect(system_address="udp://:14540")

    # 读取关键参数
    params_to_read = [
        "AS_ALT_P", "AS_ALT_MAX", "AS_PIT_P", "AS_YAW_P",
        "AS_TAKEOFF_ALT", "AS_LND_VHI",
        "CA_AS_K_LUP", "CA_AS_K_PROP"
    ]

    for p in params_to_read:
        try:
            value = await drone.param.get_float(p)
            print(f"{p} = {value}")
        except Exception as e:
            print(f"{p}: 读取失败 - {e}")

    # 修改参数 (示例: 调整起飞高度)
    await drone.param.set_float("AS_TAKEOFF_ALT", 30.0)
    print("AS_TAKEOFF_ALT 已修改为 30m")

asyncio.run(read_airship_params())
```
