## 快速上手

### 环境准备

```bash
# 安装MAVSDK (Python)
pip install mavsdk

# 或使用ROS2 (推荐)
sudo apt install ros-jazzy-mavros
```

### 最小可用代码

```python
import asyncio
from mavsdk import System

async def main():
    drone = System()
    await drone.connect(system_address="udp://:14540")  # SITL仿真

    # 等待连接
    async for state in drone.core.connection_state():
        if state.is_connected:
            break

    print("已连接, 开始监控...")

    # 实时打印飞艇状态
    async for position in drone.telemetry.position():
        async for attitude in drone.telemetry.attitude_euler():
            async for velocity in drone.telemetry.velocity_ned():
                print(f"Alt: {position.relative_altitude_m:.1f}m | "
                      f"Pitch: {attitude.pitch_deg:.1f}deg | "
                      f"Yaw: {attitude.yaw_deg:.1f}deg | "
                      f"Vx: {velocity.north_m_s:.1f} Vy: {velocity.east_m_s:.1f}")
                await asyncio.sleep(0.5)
                break
            break

asyncio.run(main())
```

## 关键约束速查表

| 约束 | 说明 |
|------|------|
| 中性浮力 | 悬停推力=0, 不能套用多旋翼假设 |
| 无Roll控制 | Roll轴依赖气动自稳定 |
| 大惯量 | Iyy=112200, Izz=145500 kg*m2, 响应迟缓 |
| 起飞/降落只激活升力电机 | M4-M7必须关闭 |
| 偏航能力受限 | 物理极限约5度, 需S形转弯策略 |
| 高度硬限位 | AS_ALT_MAX=150m, AS_ALT_MIN=2m |

## 参数前缀速查

| 前缀 | 所属模块 | 数量 |
|------|---------|------|
| AS_ | airship_att_control | ~55个 |
| BALLOON_* | ballast_control (PID) | 7个 |
| BLOWER_* | ballast_control (鼓风机) | 1个 |
| VALVE_* | ballast_control (阀门) | 1个 |
| TRIM_BALLOON_* | ballast_control (配平) | 4个 |
| CA_AS_* | 控制分配器 | 6个 |
| LNDAS_* | 着陆检测 | 6个 |

## 飞艇 vs 多旋翼对比

| 特性 | 灵云01号飞艇 | 多旋翼 |
|------|-------------|--------|
| 悬停推力 | ~0 (中性浮力) | >0 (抵消重力) |
| 失电后果 | 缓慢飘移 | 直接坠落 |
| 响应速度 | 极慢(大惯量) | 快 |
| 偏航能力 | 差(差动偏航) | 好(直接力矩) |
| Roll控制 | 无(气动自稳定) | 有(PID) |
| 着陆检测 | 悬停时landed=true | 仅落地时landed=true |
| 最大俯仰角 | +/-15度 | 通常>45度 |
