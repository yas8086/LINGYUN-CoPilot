# 昊瑞昌 DCDC CAN 通讯协议总结

> 源文件：`DCDC 通讯协议.doc`  
> 型号：HRC-GFD360-48-4K（280-500V输入，4KW，输出48V）  
> 协议版本：V1.0（2025.4.8）

---

## 一、物理层与链路层

| 项目 | 参数 |
|------|------|
| 物理标准 | ISO 11898-1、SAE J1939-11 |
| 帧格式 | CAN 2.0B **扩展帧**（29位ID） |
| 波特率 | **250 kbps** |
| 数据长度 | 每帧 8 字节 |
| 通信方式 | 主从式 + 事件触发；电源状态帧主动周期发送 |

### 29位ID结构（J1939格式）

```
  优先级(3bit) | 保留(1) | DP(1) | PF(8) | PS(8) 目的地址 | SA(8) 源地址
```

### 数据格式约定
- 所有数据以 **16进制** 传送
- 整型数据：**先低字节，后高字节**（小端序）
- 模拟量传送时 **×10**（如电压 48.0V → 480 = 0x01E0）
- 校准用模拟量 **×100**

### 地址分配

| 功能 | VMS/SU地址 | 电源地址 |
|------|-----------|---------|
| DCDC状态帧 | 0x32 | 0x47 |
| DCDC控制帧 | 0x10 | 0x30 |
| 校准参数 | 0x00 | 0x47 |
| 软件下载 | 0x00 | 0x47 |

### 控制策略
> EN信号与CAN指令：**任一为开则开机，全关才关机**

## 二、开机指令（电源控制帧）

**CAN ID：`0x18EF3010`**  
发送方：VMS → DCDC  
周期：**200ms**（需持续发送）

### 数据帧定义

| Byte | 数据名 | 说明 |
|------|--------|------|
| Byte0 | 保留 | 填0x00 |
| Byte1 | 保留 | 填0x00 |
| Byte2 | **DCDC启停** | Bit5~4：`00`=关机，`01`=开机，其余保留 |
| Byte3 | 输出电压低字节 | 分辨率：0.1V/BIT |
| Byte4 | 输出电压高字节 | 分辨率：0.1V/BIT |
| Byte5 | 输出电流低字节 | 分辨率：0.1A/BIT（限流值） |
| Byte6 | 输出电流高字节 | 分辨率：0.1A/BIT |
| Byte7 | 保留 | 填0x00 |

> **注意**：原文档Byte编号从1开始，此处按CAN标准从0开始。Byte2的Bit5~4控制开关机。

### 开机示例

**开机 + 输出48.0V + 限流80.0A：**

```
CAN ID: 0x18EF3010
Data:   00 00 10 E0 01 20 03 00
        |  |  |  |     |     |
        |  |  |  |     |     保留
        |  |  |  |     电流=0x0320=800 → 80.0A
        |  |  |  电压=0x01E0=480 → 48.0V
        |  |  Bit5~4=01(开机) → Byte2=0x10
        |  保留
        保留
```

### 关机示例

```
CAN ID: 0x18EF3010
Data:   00 00 00 00 00 00 00 00
```

## 三、调节输出电压指令

输出电压调节与开机指令在**同一帧**（电源控制帧 `0x18EF3010`）中：

- **Byte3~4**：输出电压设定值（小端序），分辨率 **0.1V/BIT**
- 计算公式：`设定值 = 目标电压 × 10`
- 范围：48V对应 480 (0x01E0)

### 常用电压设定值速查

| 目标电压 | 十进制值 | Byte3(低) | Byte4(高) |
|---------|---------|-----------|-----------|
| 43.0V | 430 | 0xAE | 0x01 |
| 45.0V | 450 | 0xC2 | 0x01 |
| 48.0V | 480 | 0xE0 | 0x01 |
| 50.0V | 500 | 0xF4 | 0x01 |
| 52.0V | 520 | 0x08 | 0x02 |
| 55.0V | 550 | 0x26 | 0x02 |
| 58.0V | 580 | 0x44 | 0x02 |

### 调压示例：开机 + 输出52.0V + 限流50.0A

```
CAN ID: 0x18EF3010
Data:   00 00 10 08 02 F4 01 00
```

## 四、电源状态帧（DCDC上报）

**CAN ID：`0x18FF3247`**  
发送方：DCDC → VMS  
周期：**500ms**

### 故障状态字节（Bit定义）

| Bit | 定义 | 0 | 1 |
|-----|------|---|---|
| Bit7 | 总故障位 | 正常 | 故障 |
| Bit6 | 保留 | - | - |
| Bit5 | 短路 | 正常 | 告警 |
| Bit4 | 过热 | 正常 | 告警 |
| Bit3 | CAN状态 | 正常 | 中断 |
| Bit2 | 输出状态 | 停机 | 开机 |
| Bit1 | 输入过压 | 正常 | 告警 |
| Bit0 | 输入欠压 | 正常 | 告警 |

## 五、其他常用命令汇总

| 功能 | 命令ID（下发） | 回应ID（上报） | 说明 |
|------|---------------|---------------|------|
| 模拟量查询 | 0x18D80047 | 0x18D84700 | 输入电压/输出电压/输出电流/温度 |
| 厂家信息查询 | 0x18D00047 | 0x18D04700 | AIIC码 |
| 软件版本查询 | 0x18D20047 | 0x18D24700 | 前/后级版本 |
| 电源条码查询 | 0x18D30047 | 0x18D34700 | 22位条码（ASCII） |
| 老化模式设置 | 0x18D10047 | 0x18D14700 | 0xAA=老化, 0x55=正常 |
| 模块电流查询 | 0x18E40047 | 0x18E44700 | 各模块电流（×100） |

### 模拟量查询回应数据格式

| Byte | 数据名 | 分辨率 |
|------|--------|--------|
| Byte0~1 | 输入电压 | 1V/BIT |
| Byte2~3 | 输出电压 | 0.1V/BIT |
| Byte4~5 | 输出电流 | 0.1A/BIT |
| Byte6 | 环境温度 | 1℃/BIT，-40偏移 |
| Byte7 | 散热器温度 | 1℃/BIT，-40偏移 |

## 六、关键注意事项

1. **控制帧必须持续发送**：周期200ms，停止发送可能导致DCDC停止工作
2. **开机条件**：EN信号与CAN指令任一为开即开机，全关才关机
3. **电压电流均为小端序**：低字节在前，高字节在后
4. **分辨率**：电压0.1V/BIT，电流0.1A/BIT，即实际值需×10后发送
5. **CAN ID固定**：控制帧 `0x18EF3010`，状态帧 `0x18FF3247`
