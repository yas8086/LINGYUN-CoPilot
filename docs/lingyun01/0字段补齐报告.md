## 1. BMS 故障字（ErrorCode 帧 `0x001FE0`）— 核心补齐

| 字段 | 位范围 | 含义 | 消息字段 | JSON 下传 | 单测 |
|---|---|---|---|---|---|
| fault_word1 | bit0-31 | 系统故障位(bit0-15) + 一级报警 Warn(bit16-31) | `BmsStatus.fault_word1`(**uint32**, 由 uint16 修正避免截断) | `fault1` | ParseErrorCode ✓ |
| fault_word2 | bit32-47 | 二级报警 Alarm | `BmsStatus.fault_word2` | `fault2` | ✓ |
| fault_word3 | bit48-63 | 三级报警 CriticalAlarm | `BmsStatus.fault_word3` | `fault3` | ✓ |

- 解析实现：`src/airship_bms/src/bms_protocol.cpp` `parse_error_code()`（64 位小端逐字节拼装）
- 消息类型修正：`src/airship_msgs/msg/BmsStatus.msg`（fault_word1 由 uint16 → uint32）
- 告警联动：`src/airship_monitor/src/monitor_node.cpp` 显式 cast 低 16 位入 DeviceAlert.code（完整 32 位经 BmsStatus/JSON 下传）
- 双链路下传：`src/airship_link/src/json_packer.cpp` `bms_to_json()` 新增 `fault1/fault2/fault3/soh`

## 3. FC 真空速 true_airspeed

| 字段 | 数据源 | 消息字段 | JSON 下传 |
|---|---|---|---|
| true_airspeed | `VfrHud.airspeed`(即真空速) | `FlightStatus.true_airspeed` | `tas` |
| airspeed | 同上 | `FlightStatus.airspeed` | `airspd` |
| groundspeed / climb_rate / throttle | VfrHud | 对应字段 | `gs` / `climb` / `thr` |

> **注意**：本机安装的 `mavros_msgs` 无 `Airspeed.msg`，无法订阅 `/mavros/airspeed` 分离 IAS/TAS，故真空速暂以 `VfrHud.airspeed` 填充。代码已注释：升级 mavros_msgs 后可改订阅分离指示/真空速（见 `src/airship_fc/src/fc_monitor_node.cpp` 头部说明）。
